MANGALMURTI LIGHTS — PRO FREE WEBSITE
Features:
- Multiple products and Buy Now
- Cart + quantity-ready structure
- COD order form
- Automatic Order ID
- WhatsApp order submission
- Mobile responsive
- All India delivery messaging

To publish free:
1. Replace YOUR_WHATSAPP_NUMBER in script.js.
2. Add your actual product photos in index.html.
3. Upload the folder to GitHub and enable GitHub Pages.

Google Sheets integration:
For automatic order saving into Google Sheets, create a Google Apps Script Web App endpoint and connect it to script.js. This requires your Google Sheet URL/Apps Script deployment URL.
